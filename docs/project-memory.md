## 必须保留的业务边界

- 订单唯一来源为 Walmart API，按系统店铺名＋客户订单号＋Walmart SKU 匹配；订单号使用 `customerOrderId`，PO 仅用于平台调用和溯源。同步平台信息时保留人工采购信息。
- 接收起点为 2026-10-01 00:00:00 PST（固定 UTC−8），结束动态取本轮开始时间；每店约 20 分钟同步，最多并行 3 店。落库后再确认符合条件的 Created 订单；只读预览不确认。完整回查、重试规则见同步文档。
- 所有订单禁止人工新增、删除；WFS 订单人工只读，不能编辑、分配或采购导入。商品、规格、图片及收件信息由官方同步维护，规格不从标题推断。
- 采购导入仅更新三项唯一匹配的已有明细；未匹配、重复、WFS、无权限行跳过并反馈。不更新采购渠道，空白保留原值。未匹配行的字段错误不阻塞其他有效行，已匹配行格式错误仍阻塞提交。
- 模板共享维护，只按去除首尾空格后的表头名称精确匹配，不依赖列号，不支持多个别名；不绑定渠道或工作表。工作表在每次上传时选择，模板支持复制。
- 分配对象为采购渠道，可多选覆盖。仅“是否可分配”为是时允许新增或替换渠道，允许清空；审核状态和供应商分配状态由系统计算。主管确认已停用。
- 管理员可访问全部；采购可访问全部店铺订单但菜单受限；运营只能访问本人绑定店铺。数据权限覆盖列表、详情、统计、导出和导入。普通账号只看自己的操作日志，日志只读、保留最近两个自然月，不记录查看请求或内部 Walmart 同步。
- 修改筛选只改草稿，点击查询才应用；首次加载、翻页、刷新仍正常请求，使用已查询条件。导出覆盖所有符合条件的数据。表头选择和拖动顺序按账号保存，勾选支持跨页。
- 发货预警及其筛选仅针对平台“已确认”，截止时间为平台发货日期次日北京时间 15:00。采购成功、采购分配时间只显示日期，后台保留精确时间，两者系统维护、不可手改。

## 首页与店铺汇总的当前口径

- 首页 `/home` 为每日订单汇总；`/store-summary` 上方为店铺概况与绩效，下方为每日店铺订单统计，不重复放首页汇总。
- 订单统计进入页面或刷新时按数据库实时计算，最近 30 天包含今天；按固定 PST 自然日归组，不随夏令时切换。每日表日期倒序，同一天店铺按销售额倒序。
- 总订单数和 WFS 订单数按店铺＋客户订单号去重；审核、不可分配、采购状态等按商品明细计数。销售额为商品金额＋运费，不含税、不重复乘数量，排除取消商品行。退款按接口实际金额归入原订单日期，缺失不冒充零。
- 在线 SKU、八项卖家责任绩效、待结算金额仍每日 PST 00:00 采集；页面刷新不直接请求 Walmart。平台失败保留并标明历史值。待结算金额使用 closingBalance，非可提现余额。
- 上下两个列表分别提供店铺多选和账号筛选，独立查询、重置、分页；店铺同框取并集，与账号、日期条件取交集。上方卡片统计其已查询条件下全部店铺，跨分页。
- 订单列表底部“今日采购渠道分配汇总”仍按北京时间，当天最新分配时间＋当前渠道计明细，每渠道各计一条，遵守账号权限但独立于列表筛选。

## 运行、验证与发布

- 本地常用 `npm run dev` / `start-local.cmd`；前端默认 5173、后端默认 3000。配置读取 `backend/.env`，勿打印凭据。
- 前端修改运行 `npm run build`，并按改动进行实际页面检查；只格式化涉及文件。数据库测试使用各业务文档规定的隔离临时库，不在业务库运行默认 `npm test` 或重置脚本。
- 正式环境：站点 `http://47.102.186.54`；工作目录 `/www/wwwroot/my-order`；容器 `my-order`；内部端口 3100；数据库 `my_order`。
- 发布：本地 `npm run release:pack` → 上传包到 `/www/backup/my-order/packages/` → 使用本次 SHA256 执行 `release.py check` → `release.py publish`。工具备份数据库、增量迁移、切换容器、验证健康与资源，日常不清数据。完整命令读发布文档。
- 浏览器连接、登录态和终端进程是临时状态，每次操作先检查；不要把旧会话的 CDP 端口、PID 当作固定配置。沿用已打开窗口，不关闭用户浏览器。
- 发布中断后先查 `/www/backup/my-order/releases/版本/state.json`、运行容器和 `.deployed-version`，避免重复启动。回退命令切换到本次发布前容器，不还原数据库。
- 历史发布报告位于本地 `releases/发布结果-版本.md`，发布包及该目录不纳入 Git；摘要中保留最近一次验证版本，详细日志不复制进摘要。
