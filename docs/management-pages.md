# 维护页列表与批量删除

导入模板、操作日志（含导入结果）、账号管理、店铺管理、采购平台/渠道/运营订单状态/采购状态维护、风险地址维护使用 `ManagementList.vue`。导入采购维持独立上传和预览流程。菜单与操作按[角色权限](permissions-audit.md)开放，不是所有角色都能访问全部维护页。

- 顶部标题及操作区、筛选区、自适应高度表格、底部分页；默认每页 20 条，可选 50/100 条。
- 关键词、创建日期区间和各页适用的角色、启用状态、同步开关、导入状态筛选；点击查询或回车生效，重置清空条件。
- 日期边界按北京时间，包含开始日和结束日；导入记录的创建日期即预览时间。
- 换页、查询、刷新或切换字典菜单时清空勾选；批量删除只作用于明确勾选的记录，必须确认。
- 原有不分页接口继续为下拉框、采购导入等流程提供兼容数据。管理页使用认证及角色权限保护的 `GET /api/management/:resource`；可删除资源使用带 CSRF 校验的 `POST /api/management/:resource/batch-delete`。操作日志及导入结果只读，没有删除操作。

删除采用事务，全批校验失败则不删除任何记录，并记录成功删除的审计信息：

- 模板、店铺配置删除保留订单及采购，导入文件也保留。导入记录和操作日志禁止人工删除，包括管理员。
- 店铺删除使用与 Walmart 同步相同的 MySQL 命名锁；正在同步时拒绝删除，成功删除先关闭并移除调度配置。订单回执保留。
- 当前登录账号、最后一个启用的总账号不能删除。删除其他账号遵循既有外键行为，订单和采购记录保留；列表的店铺所属账号根据店铺绑定关系显示，不作为采购渠道分配对象。
- 模板已不再绑定采购渠道或工作表，字典维护不再依赖模板渠道绑定。修改或删除字典选项不批量改写历史订单名称。
- 风险地址删除后，实时匹配的订单风险标记解除。
- 风险地址页新增“下载导入模板”和“Excel 批量上传”。上传弹窗仅在点击“开始导入”后提交，处理中显示加载态并禁止重复操作；完成后刷新列表，跳过行的地址、行号和原因分页展示。导入只新增有效且唯一的地址，不覆盖已有数据，规则见[采购字段与风险地址](procurement-fields.md)。
- 检查列表版本，记录已更改或已被删除时要求刷新后重新勾选。

导入模板支持复制，自动生成独立副本并避开已有名称。创建、编辑弹窗只滚动映射数据行，基本信息、工具栏、表头和操作按钮固定；列映射只按表头名称，不展示列号。详见[采购导入](purchase-import.md)。

升级仍执行项目统一增量迁移，不单独清空维护表。自动删除验证使用独立的一次性测试库：

```powershell
$env:DB_NAME = 'my_order_management_test_' + [DateTimeOffset]::UtcNow.ToUnixTimeMilliseconds()
node --test backend/test/management-integration.test.js
Remove-Item Env:DB_NAME
```

测试库名称必须匹配 `my_order_management_test_数字`，测试结束只删除本次创建的测试库。
