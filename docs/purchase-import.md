# 采购导入

前端订单 Excel 导入菜单、页面路由、空列表导入按钮和人工新增明细按钮已注释保留。原代码保留，但后端人工新增、旧订单导入与删除接口均拒绝写入，订单只能从 Walmart 官方接口接入。

采购模板必须映射系统店铺名（shopName）、客户订单号（orderNumber）、Walmart SKU（walmartSku）和至少一个可更新采购字段（不含采购渠道）。采购 SKU、采购渠道不参与目标定位。

- 三项唯一匹配已有商品明细：更新已映射且非空的采购字段，空白字段保留原值；不覆盖平台信息或采购人员。
- 三项未匹配、匹配到多个旧明细、店铺名或 Walmart SKU 为空：跳过，不新增订单或商品明细。
- WFS 订单、运营账号无所属店铺权限的行跳过，结果中列出原因；管理员和采购可处理全部店铺的非 WFS 订单。提交时再次检查权限和目标状态。
- 同批多行匹配同一个唯一目标：按文件上传区顺序及文件内行顺序更新，后面的非空字段生效。
- 已匹配行的数据格式错误仍需修正后提交；未匹配行即使存在字段格式错误也跳过，不阻止其他正确行提交，原错误明细和跳过原因均保留。预览分别返回错误总数和阻塞错误数，提交按钮及后端校验以阻塞错误数为准。
- 预览保存采购信息摘要；提交时仅采购信息变化、目标删除或出现重复才返回冲突，要求重新预览，不改为新增。Walmart 更新平台信息不会阻止采购提交。升级前没有摘要的旧预览继续严格校验版本，冲突时需重新预览。

预览、完成页及历史记录均提供完整跳过清单，包含文件名、Excel 行号、系统店铺名、客户订单号、Walmart SKU 和原因，前端每页 20 行。全未匹配时也可完成导入记录，更新数为 0。旧匹配规则生成的未提交采购预览必须重新生成。

验证：`node --test backend/test/import-matching.test.js backend/test/import-boundaries.test.js`。数据库集成测试文件为 `backend/test/purchase-import-integration.test.js`，只接受显式指定的 `my_order_purchase_test_数字时间戳` 临时数据库；自动创建并清理，不使用业务数据库。

## 模板与工作表

模板只保存名称、表头行和字段映射，不绑定采购渠道或工作表。编辑模板时上传的示例文件工作表仅用于读取表头，不随模板保存。旧数据库绑定列保留兼容性，不再参与导入；旧渠道映射变为空映射，Excel 源表头保留。

每个采购上传区上传文件后单独选择本次工作表：单工作表自动选中，多工作表须明确选择，替换文件后重置选择。预览请求在每个 source 中提供 `sheetName`，后端校验工作表存在，历史快照保留所选工作表。

采购渠道无论来自旧模板、Excel 还是旧的未提交预览，都不会更新。采购渠道仍通过订单页面分配；WFS 订单继续跳过，其他匹配、空值保留和并发校验规则不变。

## 按表头名称匹配

模板维护不再显示或依赖列号。每条映射保存 Excel 表头名称和目标系统字段；导入时从本次工作表的表头行重新定位实际列。因此列顺序改变不需要修改模板，旧模板残留的列号也不参与匹配。

- 名称去除首尾空格后精确匹配，保留大小写及内部字符差异；不支持一条映射填写多个别名。表头名称不同的文件应调整模板或复制模板后分别维护。
- 同一已映射表头在文件中出现多次时拒绝导入，不能用旧列号消歧。请先将 Excel 表头改为唯一名称。
- 缺少订单号必填表头会报错；缺少其他列会提示并保留对应原值。店铺名或 Walmart SKU 缺列后无法满足三项匹配，其数据行会跳过，不匹配空身份订单。
- 未选择系统字段的源表头仍保存在模板中，导入不读取、不校验这些列。生效映射的源表头和目标字段不能重复。
- 模板保存与采购导入校验分开：实际采购预览必须映射店铺名、订单号、Walmart SKU，以及至少一个可更新采购字段。旧模板含商品、收件或运营字段的生效映射时，应取消这些映射后使用。

新增、编辑模板弹窗固定基本信息、映射工具栏、表头和底部按钮，只滚动映射数据行。

## 复制与只读字段

模板列表支持“复制”，服务端创建独立模板，复制表头行及映射（包括未选系统字段的源表头）。自动命名为“原名称 - 副本”，重名时追加“(2)”等编号。修改副本不影响原模板；模板仍由有权限的账号共享维护。

商品及收件信息、平台字段不能通过采购导入更新。采购成功时间不提供映射或人工编辑入口，只在正式提交时根据采购状态变化自动记录，详见[采购成功时间](procurement-fields.md#采购成功时间与跟踪号提醒)。采购状态不在启用选项中则跳过该字段并提示，不改变原状态或计时。

“导出数据填写采购信息”同时保留商品数量和采购数量。商品数量与运营备注仅供参考，不能通过采购导入回写，不要为这两列表头选择目标字段；采购数量可映射到同名字段，按正整数校验，空白保留原值。旧“数量”表头仍对应商品数量，不自动改为采购数量。

“主管确认”已停用。旧模板在编辑、复制或预览时保留源表头并自动改为不映射，不影响其他有效采购字段；只剩该采购字段的模板需要配置其他有效采购字段才能导入。包含该字段的旧未提交预览会提示重新预览。已有数据库列和历史值保留，当前接口不再读取、写入或导出该字段。
